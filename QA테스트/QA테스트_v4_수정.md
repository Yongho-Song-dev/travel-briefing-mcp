# Travel Briefing MCP QA 테스트 v4 수정 내역

> 작성일: 2026-07-22 (KST)  
> 기준 문서: `QA테스트/QA테스트_v4_리뷰.md`  
> 수정 범위: 9개 지원 국가의 문화·안전·교통·결제·생활 상세 팁, 준비물 및 현재상황 응답 연결, 지역별 여행경보 표현, 관련 문서와 회귀 테스트  
> 주의: 이 문서는 현재 작업 트리에 반영된 v4 1차 수정사항을 기록한다. v4 리뷰에서 추가로 발견된 P0~P2 개선 과제는 아직 구현하지 않았으며 10절에 별도로 정리한다.

## 1. 수정 결과 요약

기존 `travel_tips`는 국가별로 3개의 짧은 준비 문구만 제공해 문화적 배경이나 현지 행동 요령을 충분히 설명하지 못했다. v4에서는 9개 국가 JSON에 구조화된 `local_tips`를 추가하고, 브리핑·현재상황·체크리스트에서 재사용할 수 있는 공통 렌더러를 연결했다.

주요 반영 결과:

- 9개국 모두 `local_tips_title`, `local_tips_last_reviewed`, `local_tips`를 갖도록 확장했다.
- 총 52개의 상세 팁을 추가했다.
- 각 상세 팁은 제목과 2개 이상의 설명으로 구성했다.
- 첫 번째 설명은 문화·상황의 배경, 두 번째 설명은 사용자가 현장에서 취할 행동을 중심으로 작성했다.
- `get_trip_briefing`과 `compose_checklist`는 상세 팁 전체를 반환한다.
- `get_current_status`는 여행경보와 함께 간결한 현지 행동 팁을 반환한다.
- 발리 예시에 포함된 소지품, Canang Sari, 오른손 예절, 보행, 환전, 우산·우비를 모두 데이터화했다.
- 일부 지역만 경보가 발령된 국가를 전국 전체 위험으로 단정하지 않도록 여행경보 파싱과 렌더링을 보강했다.
- 준비물·현지 관습 질문이 상세 팁 도구로 연결되는지 검사하는 회귀 테스트를 추가했다.

모든 국가의 `static` 객체에 다음 공통 필드를 추가했다.

```json
{
  "local_tips_title": "국가별 현지 팁 제목",
  "local_tips_last_reviewed": "2026-07-22",
  "local_tips": [
    {
      "title": "사용자가 바로 이해할 수 있는 행동 중심 제목",
      "details": [
        "문화·상황적 배경",
        "현지에서 취할 구체적인 행동"
      ]
    }
  ]
}
```

기존 `travel_tips`는 전자입국카드·결제앱처럼 출발 전에 빠르게 확인할 짧은 정보로 유지하고, `local_tips`는 현지에서 이유를 이해하고 행동할 수 있는 상세 정보로 분리했다.

## 5. `tb_helpers.py` — 상세 팁 및 지역별 경보 렌더링

### 5.1 `_render_local_tips_md()` 추가

새 공통 렌더러를 추가했다.

- 국가 JSON의 `local_tips`를 번호 목록으로 출력한다.
- 상세 모드에서는 문화·상황 배경과 행동 요령을 모두 보여준다.
- `compact=True`에서는 현재상황 응답이 지나치게 길어지지 않도록 각 팁의 마지막 행동 문장만 보여준다.
- `local_tips_title`이 없으면 국가명을 이용한 기본 제목으로 폴백한다.
- 문자열 형태의 예전 팁도 처리해 데이터 마이그레이션 중 오류를 막는다.
- 국가별 검토일과 `지역·시설별 차이 및 규정 변경 가능성` 면책 문구를 표시한다.

### 5.2 `_render_briefing_md()`에 상세 팁 연결

- 기존 비자·전압·시차·통화·긴급번호·팁 문화·대사관 정보 뒤에 국가별 상세 팁을 추가했다.
- 상세 팁이 없는 국가 데이터는 기존 브리핑만 반환하도록 폴백을 유지했다.
- 준비물 질문에 어댑터·현금·비자 행동 항목이 함께 반환되도록 기존 챙길 것 블록과 상세 팁을 결합했다.

### 5.3 `_advisory_summary()` 추가

- 지역별 경보가 있을 때 전국에 적용되는 비-일부 단계만 별도로 계산한다.
- 전국 단계보다 높은 일부 지역 경보가 존재하는지를 `has_regional`로 반환한다.
- 상단 요약에서 국가 전체를 일부 지역의 최고 단계로 오인하지 않도록 공통 계산을 제공한다.

### 5.4 `_render_alert_md()` 수정

- 제목을 `현재 안전 상황`에서 `여행경보 현황` 중심으로 정리했다.
- 조회 실패 상태를 녹색 안전 신호와 구분해 흰색 상태로 표시한다.
- 전국 또는 전국 일반 단계를 먼저 표시한다.
- 일부 지역 경보가 있으면 여행금지→출국권고→여행자제→여행유의 순으로 지역을 나열한다.
- 지역마다 단계가 다르다는 안내와 경보 단계 범례를 함께 제공한다.
- 발효일과 외교부 해외안전여행 확인 링크를 유지한다.

### 5.5 일정·준비 요약의 경보 표현 수정

수정 함수:

- `_render_essentials_md()`
- `_prep_summary_line()`

변경 내용:

- 두 함수 모두 `_advisory_summary()`를 사용해 전국 단계 기준으로 요약한다.
- 일부 지역 경보가 있으면 `지역별 상이 — 목적지 확인`을 표시한다.
- API 조회 실패는 안전 확인이 된 것처럼 표시하지 않고 직접 확인을 안내한다.

## 6. `travel_briefing_mcp.py` — MCP 도구 응답 및 선택 설명 수정

### 6.1 공통 렌더러 연결

- `_render_local_tips_md`를 가져와 브리핑·현재상황·체크리스트에서 재사용한다.
- 새로운 MCP 도구는 추가하지 않아 기존 7개 도구 구성을 유지했다.

### 6.2 `get_trip_briefing` 수정

- 도구 설명의 호출 의도에 `packing`, `local customs`, `country-specific tips`를 추가했다.
- `발리에서 조심할 점은?`, `대만 준비물 알려줘`를 대표 예시로 추가했다.
- 비자·전압 질문뿐 아니라 준비물과 현지 문화 질문에도 호스트 LLM이 이 도구를 선택하도록 범위를 넓혔다.
- 실제 응답은 `_render_briefing_md()`를 통해 상세 팁 전체를 포함한다.

### 6.3 `get_current_status` 수정

- 도구 설명에 현재 상황, 안전, 지역별 여행경보 질문 예시를 추가했다.
- 국가 전체의 안전·위험을 단정하지 말고 사용자가 말한 목적지와 지역별 경보를 연결하도록 설명했다.
- 여행경보 마크다운 뒤에 `compact=True` 상세 팁을 붙였다.
- 현재 경보와 함께 소지품·교통·결제·예절의 행동 요령을 빠르게 확인할 수 있게 했다.

### 6.4 `compose_checklist` 수정

- 기존 3개 `travel_tips`의 `국가 특이사항` 섹션은 유지했다.
- 그 아래에 `_render_local_tips_md()`의 상세 문화·현지 생활 팁을 추가했다.
- 상세 팁이 없는 데이터에 대해서는 해당 섹션을 생략한다.
